🤖 How to use it in your bot

    

      
1
        
Put the API base address in your bot code:
https://vexora-api-orcin.vercel.app

      
2
        
Send the user's link to the endpoint you need, for example:
/api/ttdl?url=<link>

      
3
        
The JSON reply contains status: true and the download link — just send that file to the user. Done!
